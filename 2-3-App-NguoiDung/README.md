# Ứng dụng Người dùng (Sentio User App)

Đây là mã nguồn của ứng dụng chính dành cho khách hàng (End-User).

## Cấu trúc

### 1. Frontend (`fe/`)
- **Framework:** Next.js 16 (App Router).
- **Ngôn ngữ:** TypeScript.
- **Styling:** Tailwind CSS v4.
- **Chức năng:** Giao diện mua sắm, phòng thử đồ ảo (AR/AI), quản lý giỏ hàng.

### 2. Backend (`be/`)
- **Framework:** FastAPI (Python).
- **Chức năng:**
    - API Gateway kết nối với AI Models.
    - Xử lý nghiệp vụ mua sắm.
    - Quản lý người dùng và xác thực.

## Hướng dẫn chạy
Vui lòng xem file `README.md` chi tiết bên trong từng thư mục con (`fe` và `be`).
