# Dữ liệu Hệ thống (System Data)

Thư mục này chứa các cấu hình và script để thiết lập cơ sở dữ liệu chính thức cho ứng dụng Sentio.

## Thành phần
- **`PostgreSQL/`**: Chứa các file SQL scripts để khởi tạo bảng (Schema), Views, và Functions cho database.
- **`Supabase-Storage/`**: Cấu hình cho việc lưu trữ file media (ảnh sản phẩm, ảnh người dùng) trên Supabase.
- **`SETUP_GUIDE.md`**: 📄 **Tài liệu quan trọng** hướng dẫn chi tiết cách import dữ liệu và kết nối database.

## Quy trình
Dữ liệu sau khi được xử lý sạch ở `2-0DataDuKien` sẽ được chuẩn hóa và import vào hệ thống thông qua các hướng dẫn tại đây.
